# Word count

Write a program in `Main.java`. Print `Enter a sentence:` on its own line, then read one line of words
separated by single spaces. Then print three lines:

```
Words: <the number of words>
Letters: <the number of letters in all the words>
Longest: <the longest word>
```

If several words are equally long, the longest is the first of them.

## Sample run

Input is shown here for clarity; your program does not print it.

```
Enter a sentence:
the quick brown fox
Words: 4
Letters: 16
Longest: quick
```

Each output line of the sample run is one test. The rest are hidden.

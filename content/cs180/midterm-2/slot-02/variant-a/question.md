# Q2: Seedling

Complete the class `Seedling` in `Seedling.java`.

- Private fields hold the seedling's name and its height in whole centimetres, both set by the constructor.
- `getName()` and `getHeightCm()` return them, and `setHeightCm(int heightCm)` changes the height.
- `isReadyToPlant()` returns `true` when the height is at least 15 centimetres.
- The static method `getCount()` returns how many `Seedling` objects have been created.

`Main.java` is read-only. Run it to try your class.

# Q5: Booking

The class `Booking` in `Booking.java` is complete except for `toString`. Write `toString` so that it returns the
booking in exactly this form, with the nightly rate to two decimals:

```
Booking[guest=Ana Ruiz, nights=3, rate=$89.50]
```

`Main.java` is read-only. Run it to try your class.

## Sample run

Running `Main.java` prints:

```
Booking[guest=Ana Ruiz, nights=3, rate=$89.50]
```

The sample run is one of the tests. The rest are hidden.

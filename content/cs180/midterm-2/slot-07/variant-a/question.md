# Q7: Table number

Write a program that asks for a table number from 1 to 40, using the prompt `Enter a table number:` on its own
line, until a valid one is entered.

- If what is typed is not a whole number, print `Invalid: not a whole number` and ask again.
- If it is a whole number outside 1 to 40, print `Invalid: not from 1 to 40` and ask again.

When a valid number is entered, print `Table: ` followed by the number, then `Attempts: ` followed by how many
times the user was asked. The program must not crash, whatever is typed.

## Sample run

```
Enter a table number:
[45]
Invalid: not from 1 to 40
Enter a table number:
[12]
Table: 12
Attempts: 2
```

The sample run is one of the tests. The rest are hidden.

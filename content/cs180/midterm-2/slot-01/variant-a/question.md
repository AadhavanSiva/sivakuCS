# Q1: Hire notice

Write a program that writes these three lines to a file named `notice.txt`, replacing the file if it already
exists. Each line ends with a line break. The program prints nothing.

```
Pier 7 Kayak Hire
Open 9am to 6pm
Life jackets provided
```

## Sample run

The program prints nothing. Afterwards, `notice.txt` holds:

```
Pier 7 Kayak Hire
Open 9am to 6pm
Life jackets provided
```

The sample run is one of the tests. The rest are hidden.

# Q4: Quiz scores tests

`QuizScores.java` describes a list of quiz scores in its comments. You will not see the class that implements it,
`QuizScoreList`, which has a constructor with no arguments.

Write JUnit 5 tests for `QuizScoreList` in `QuizScoresTest.java`. Your tests are run against a correct
`QuizScoreList` and against four others, each with one bug:

1. an empty list;
2. a boundary stated in the comments;
3. invalid input that should be rejected;
4. a computed value.

You score 2 points if all your tests pass on the correct `QuizScoreList`, and 3 points for each buggy one where at
least one of your tests fails. **If any of your tests fails on the correct `QuizScoreList`, the question scores
0.** The starter's one test passes on the correct class, so it is worth 2 points as given.

Press Test to run your tests.

# Q2: Weekend visitors

Write a program that reads the number of visitors on Saturday and on Sunday, both whole numbers, using the
prompts `Visitors on Saturday:` and `Visitors on Sunday:`, each on its own line.

Print `Total visitors: ` followed by the sum, then `Average per day: ` followed by the average of the two
numbers with exactly two decimals.

## Sample run

```
Visitors on Saturday:
[148]
Visitors on Sunday:
[162]
Total visitors: 310
Average per day: 155.00
```

The sample run is one of the tests. The rest are hidden.

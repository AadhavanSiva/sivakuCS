# Q5: Member code

Write a program that reads a member's name using the prompt `Enter your full name:` on its own line. The name
is a first name and a last name separated by one space; each has at least four letters, in any mix of upper and
lower case.

Print `Initials: ` followed by the first letter of each name in upper case.

Then print `Member code: ` followed by the last two letters of the first name in upper case, the first two
letters of the last name in lower case, and the number of letters in the two names together.

## Sample run

```
Enter your full name:
[Rosalind Thackeray]
Initials: RT
Member code: NDth17
```

The sample run is one of the tests. The rest are hidden.

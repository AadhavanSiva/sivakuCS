# Q6: Banner letters

Write a program that reads a line of text using the prompt `Enter the banner text:`, then a line whose first
character is the character to look for, using the prompt `Enter a character:`. Each prompt is on its own line.

Print `Count: ` followed by the number of times the character appears in the text, ignoring case. Then print
`First index: ` followed by the index of its first appearance, or -1 if it does not appear.

## Sample run

```
Enter the banner text:
[Grand Opening Sale]
Enter a character:
[n]
Count: 3
First index: 3
```

The sample run is one of the tests. The rest are hidden.

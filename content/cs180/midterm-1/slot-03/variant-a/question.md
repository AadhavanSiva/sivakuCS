# Q3: Division check

Write a program that reads two whole numbers, a dividend and a divisor, using the prompts `Enter the dividend:`
and `Enter the divisor:`, each on its own line. Either number may be negative.

If the divisor is 0, print `Division by zero is undefined.` and nothing else.

Otherwise print `Divisible: yes` if the divisor divides the dividend with nothing left over, or `Divisible: no`
if it does not. Then print `Quotient: ` and `Remainder: `, each followed by the result of Java's `/` and `%` on
the two numbers.

## Sample run

```
Enter the dividend:
[47]
Enter the divisor:
[6]
Divisible: no
Quotient: 7
Remainder: 5
```

The sample run is one of the tests. The rest are hidden.

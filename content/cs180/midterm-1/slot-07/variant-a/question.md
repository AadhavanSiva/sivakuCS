# Q7: Backwards words

Write a program that reads a line of words separated by single spaces, using the prompt `Enter the words:` on
its own line. Words are made of letters only.

Print `Reversed: ` followed by the words in reverse order, separated by single spaces. Then print `Letters: `
followed by the total number of letters in all the words.

## Sample run

```
Enter the words:
[lanterns float over the lake]
Reversed: lake the over float lanterns
Letters: 24
```

The sample run is one of the tests. The rest are hidden.

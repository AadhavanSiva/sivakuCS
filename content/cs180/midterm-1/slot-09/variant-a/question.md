# Q9: Routine scores

Write a program that reads the number of scores, at least 1, using the prompt `How many scores?`, then each
score, a whole number from 0 to 100, using the prompt `Enter a score:`. Each prompt is on its own line. Store the
scores in an array.

Print `Best index: ` followed by the index of the highest score; if it appears more than once, give the first.
Then print `Average: ` followed by the average with exactly two decimals. Then print `Above average: ` followed
by how many scores are strictly greater than the true average.

## Sample run

```
How many scores?
[5]
Enter a score:
[72]
Enter a score:
[91]
Enter a score:
[64]
Enter a score:
[88]
Enter a score:
[79]
Best index: 1
Average: 78.80
Above average: 3
```

The sample run is one of the tests. The rest are hidden.
